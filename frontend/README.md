# ResumePilot Frontend

This folder contains the React + Vite frontend for ResumePilot.

For the complete project README, screenshots, architecture diagrams, feature details, setup instructions, and API documentation, see the root-level [`README.md`](../README.md).

## Quick Start

```bash
npm install
npm run dev
```

The frontend uses `VITE_API_BASE_URL` for the backend API and falls back to `http://localhost:5000/api` during local development.
